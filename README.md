1. 파일 및 소스 코드 구조확장자: .sjl (인코딩: UTF-8)단일 행 실행 및 주석 규칙: 소스 파일의 첫 번째 줄(Line 1)만 코드로 인식하여 실행합니다. 첫 번째 개행 문자(\n) 이후에 등장하는 모든 텍스트는 전부 주석으로 처리되어 무시됩니다.토큰(Token)과 구문(Statement)의 분리:모든 토큰(키워드, 식별자, 리터럴, 연산자)은 공백(스페이스바 1개 이상)으로 구분합니다.파서는 공백으로 쪼개진 토큰들을 읽어 내려가며 아래 4번 항목에 정의된 8가지 명령어 구문(Statement) 단위로 묶어 AST(추상 구문 트리) 또는 명령어 배열을 생성합니다.2. 데이터 타입 및 리터럴 (ㅗ 표기법)유일한 자료형: 부호 있는 64비트 정수 (int64_t) 하나만 존재합니다.정수 리터럴: 오직 'ㅗ' 문자의 연속으로만 숫자를 표현합니다. 'ㅗ'가 $n$개 연속될 때($n \ge 1$), 그 값은 $2^{n-1}$입니다.ㅗ = $2^0 = 1$ㅗㅗ = $2^1 = 2$ㅗㅗㅗ = $2^2 = 4$ㅗㅗㅗㅗ = $2^3 = 8$0이나 홀수/음수 표현법: 리터럴 자체로는 $2$의 거듭제곱만 표현할 수 있으므로, 0이나 3, 음수 등은 변수 선언 후 뺄셈 연산(꺼져)을 통해 만들어야 합니다.3. 식별자 (변수명 및 라벨명) 규칙예약어 시작 금지: 식별자는 다음 키워드로 시작할 수 없습니다.금지 접두사: 느, 미친, ㅗ, 뒤져, 또라이, 미쳤냐, 인실좆, 꺼져, ㅋ, 새끼기호 금지: 식별자 내부에는 공백이나 세미콜론(;)이 포함될 수 없습니다.4. 명령어 구문 (Statement) 명세파서는 토큰 스트림을 왼쪽에서 오른쪽으로 읽으며, 각 구문이 요구하는 토큰 개수만큼 소비하여 하나의 독립된 명령어(Instruction)로 등록합니다.분류구문 형태 (토큰 단위)소비 토큰 수동작 설명1. 모듈 임포트미친<파일명> 새끼2개첫 토큰이 미친으로 시작하고 두 번째 토큰이 새끼인 경우, <파일명>.sjl의 첫 줄 코드를 현재 위치에 인라인(Inline)으로 삽입합니다. (예: 미친입출력 새끼 $\rightarrow$ 입출력.sjl 임포트)2. 변수 선언느<변수명>; [초기값]1개 또는 2개첫 토큰이 느로 시작하고 ;로 끝나면 <변수명>을 선언합니다.• 바로 다음 토큰이 리터럴(ㅗ...)이나 기존 변수명이면 그 값으로 초기화합니다 (2토큰 소비).• 다음 토큰이 다른 명령어 키워드이면 기본값 0으로 초기화합니다 (1토큰 소비).3. 단순 대입<변수명> ㅋ <값>3개<변수명> = <값>을 수행합니다. <값> 자리에는 정수 리터럴(ㅗ...) 또는 다른 <변수명>이 올 수 있습니다.4. 뺄셈 대입<변수명> 꺼져 ㅋ <값>4개<변수명> -= <값>을 수행합니다.5. 차감 대입<변수명> ㅋ <값1> 꺼져 <값2>5개<변수명> = <값1> - <값2>를 수행합니다.6. 표준 출력인실좆 <값>2개<값>(변수 또는 리터럴)을 정수로 평가하여 화면에 출력하고 줄바꿈(\n)합니다.7. 라벨 정의뒤져 <라벨명>2개현재 명령어 위치를 <라벨명>으로 등록합니다. 실행 시에는 아무 동작도 하지 않고 넘어갑니다(NOP).8. 무조건 점프또라이 <라벨명>2개프로그램 카운터(PC)를 뒤져 <라벨명>이 정의된 위치로 즉시 이동시킵니다.9. 조건부 스킵미쳤냐 <변수명>2개<변수명>의 값을 평가합니다.• 값이 0이면: 바로 다음 명령어(Statement)를 정상 실행합니다.• 값이 0이 아니면: 바로 다음 명령어(Statement) 1덩어리 전체를 건너뛰고(PC + 2) 그다음 명령어를 실행합니다.5. 실행 흐름 및 종료 규칙전처리(Pre-processing): 인터프리터는 코드 실행 전 미친<파일명> 새끼 구문을 먼저 찾아 텍스트를 치환하고, 전체 구문을 스캔하여 뒤져 <라벨명>의 위치(인덱스)를 심볼 테이블에 미리 등록합니다. (따라서 라벨이 점프문보다 뒤에 있어도 정상 이동합니다.)순차 실행: 0번 명령어부터 순서대로 실행합니다.종료: 마지막 명령어를 실행한 뒤 더 이상 실행할 명령어가 없으면 프로그램이 정상 종료(Exit Code 0)됩니다.
