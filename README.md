# 시발 장애인 언어 (.sjl) 공식 명세서 v1.0

## 1. 파일 및 소스 코드 구조
- **확장자:** `.sjl` (인코딩: UTF-8)
- **단일 행 실행 규칙:** 소스 파일의 **첫 번째 줄(`Line 1`)만 코드로 인식**하여 실행합니다. 첫 번째 개행 문자(`\n`) 뒤에 오는 모든 텍스트는 주석으로 처리되어 무시됩니다.
- **토큰 구분:** 모든 토큰(키워드, 식별자, 리터럴, 연산자)은 **공백(스페이스바 1개 이상)**으로 구분합니다.

---

## 2. 데이터 타입 및 리터럴 (`ㅗ` 표기법)
- **자료형:** 부호 있는 64비트 정수 (`int64_t`) 하나만 존재합니다.
- **정수 리터럴:** 오직 `'ㅗ'` 문자의 연속으로만 숫자를 표현합니다. `'ㅗ'`가 $n$개 연속될 때($n \ge 1$), 그 값은 **$2^{n-1}$**입니다.
  - `ㅗ` = $2^0 = 1$
  - `ㅗㅗ` = $2^1 = 2$
  - `ㅗㅗㅗ` = $2^2 = 4$
  - `ㅗㅗㅗㅗ` = $2^3 = 8$
- **0 또는 음수 표현:** 리터럴 자체로는 $2$의 거듭제곱만 표현할 수 있으므로, `0`이나 `3`, 음수 등은 변수 선언 후 뺄셈 연산(`꺼져`)을 조합해서 만들어야 합니다.

---

## 3. 식별자 (변수명 및 라벨명) 규칙
- **금지된 접두사:** 식별자는 다음 키워드로 시작할 수 없습니다.
  - `느`, `미친`, `ㅗ`, `뒤져`, `또라이`, `미쳤냐`, `인실좆`, `꺼져`, `ㅋ`, `새끼`
- **기호 제약:** 식별자 내부에는 공백이나 세미콜론(`;`)을 포함할 수 없습니다.

---

## 4. 명령어 구문 (Statement) 명세

파서는 토큰 스트림을 왼쪽에서 오른쪽으로 읽으며, 각 구문이 요구하는 토큰 개수만큼 소비하여 명령어를 실행합니다.

| 분류 | 구문 형태 (토큰 단위) | 소비 토큰 수 | 동작 설명 |
| :--- | :--- | :---: | :--- |
| **1. 모듈 임포트** | `미친<파일명>` `새끼` | 2개 | 첫 토큰이 `미친`으로 시작하고 두 번째가 `새끼`인 경우, `<파일명>.sjl`의 첫 줄 코드를 인라인 삽입합니다. (예: `미친입출력 새끼`) |
| **2. 변수 선언** | `느<변수명>;` `[초기값]` | 1~2개 | 변수를 선언합니다. 바로 뒤에 초기값(리터럴 또는 변수명)이 오면 대입하고(2토큰), 바로 다른 명령어가 오면 `0`으로 초기화합니다(1토큰). |
| **3. 단순 대입** | `<변수명>` `ㅋ` `<값>` | 3개 | `<변수명> = <값>`을 수행합니다. |
| **4. 뺄셈 대입** | `<변수명>` `꺼져` `ㅋ` `<값>` | 4개 | `<변수명> -= <값>`을 수행합니다. |
| **5. 차감 대입** | `<변수명>` `ㅋ` `<값1>` `꺼져` `<값2>` | 5개 | `<변수명> = <값1> - <값2>`를 수행합니다. |
| **6. 표준 출력** | `인실좆` `<값>` | 2개 | `<값>`의 평가된 정수 값을 화면에 출력하고 줄바꿈합니다. |
| **7. 라벨 정의** | `뒤져` `<라벨명>` | 2개 | 현재 명령어 위치를 `<라벨명>` 라벨로 등록합니다 (실행 시 NOP). |
| **8. 무조건 점프** | `또라이` `<라벨명>` | 2개 | 프로그램 카운터(PC)를 `뒤져 <라벨명>` 위치로 즉시 이동시킵니다. |
| **9. 조건부 스킵** | `미쳤냐` `<변수명>` | 2개 | 변수 값이 **`0`이면** 다음 명령어 1개를 정상 실행하고, **`0이 아니면`** 다음 명령어 1개 전체를 건너뜁니다. |

---

## 5. 실행 흐름 및 종료 규칙
1. **전처리:** `미친<파일명> 새끼` 구문을 재귀적으로 인라인 치환하고, 모든 라벨(`뒤져 <라벨명>`)의 위치를 미리 스캔하여 심볼 테이블에 등록합니다.
2. **순차 실행:** 0번 명령어부터 순서대로 실행합니다.
3. **종료:** 마지막 명령어를 실행한 뒤 더 이상 실행할 명령어가 없으면 프로그램이 정상 종료됩니다.
